# MITM 计划：请求解密（查看 HTTP / HTTPS 请求内容）

> 状态：**暂缓**（2026-11-17 讨论后决定先不做），本文记录方案，需要时再评估。
> 参考：Surge 的 MitM 与 HTTP Capture、Stash 的 MitM、Charles / Proxyman。

## 目标

在 App 里看到经 Velum 的请求到底发了什么：方法、URL、请求与响应的头和正文、耗时、状态码。
用于调试接口、排查「某个 App 为什么连不上」、确认规则是否命中预期的请求。

非目标：改写请求 / 响应（Surge 的 Script、Rewrite）、脚本、断点。以后可在本文基础上扩展。

## 原理

1. **根证书**：Velum 在本机生成一张专属根 CA（私钥只存本机，`0600`，不进订阅、不同步）。
   用户在 App 里点「安装并信任」→ 写入登录钥匙串并设为信任（`security add-trusted-cert`，需用户确认 / 密码）。
2. **只解密名单里的域名**（MitM 主机名，支持 `*.example.com`，默认空、功能默认关）：
   - TCP 连接嗅探到 SNI 命中名单 → 引擎用根 CA 当场签发该域名的叶证书（按域名缓存，有效期短），与应用完成 TLS 握手；
   - 引擎另起一条到真实服务器的 TLS 连接，**照常校验**服务器证书（校验失败则断开并记录，绝不降级）；
   - 两边之间是明文，解析 HTTP 并记录，再原样转发。
3. **明文 HTTP**（80 等端口）：不需要证书，按名单（或单独开关）直接解析记录。
4. **出站不变**：解密后的上游连接仍按原来的规则与策略组走（直连 / 节点），记录里标出走了哪条规则、哪个节点。

## 关键设计

| 项 | 方案 |
| :--- | :--- |
| TLS 实现 | 引擎已有 BoringSSL（`boring` / `tokio-boring`）：签发证书用 `X509Builder`，服务端握手用 `SslAcceptor` |
| 叶证书 | 名单内域名按需签发，SAN = SNI，RSA 2048 或 P-256；内存缓存（LRU），有效期 ≤ 1 年（Apple 对 825 天以上的证书不信任） |
| ALPN | 第一版只协商 `http/1.1`（解密连接上不提供 h2）；第二版支持 h2（分帧 + HPACK 解析） |
| HTTP/3 | 名单内域名的 UDP 443 拒绝，迫使客户端回退 TCP |
| 嗅探时机 | 复用现有 TLS 嗅探（`stack.rs` 的 `sniff_tcp`）：SNI 在手后决定是否 MITM，再走原来的规则 |
| 记录 | 内存环形缓冲（最近 500 条），单个正文上限 1 MB（超出截断并标注），退出即清空；不落盘 |
| 解压 | 记录时对 gzip / br / deflate 解压后展示；转发保持原样 |
| 失败处理 | 客户端拒绝我们的证书（证书固定）→ 记录「客户端不信任」，该域名短期内自动绕过 MITM，避免反复失败 |
| 安全 | 根 CA 私钥仅本机；关闭功能时提示可一键从钥匙串移除信任；名单为空时不做任何解密 |

## 界面

- **设置 → 请求解密**：开关、MitM 主机名列表、根证书状态（未生成 / 未信任 / 已信任）与安装 / 移除按钮。
- **新增「请求」页**：列表（时间、方法、主机、路径、状态码、大小、耗时、进程），过滤与搜索；
  详情：请求 / 响应头、正文（JSON 格式化、图片预览、十六进制）、命中规则与节点；「复制为 curl」。
- **导出 HAR**：选中或全部导出，可用 Charles、Chrome DevTools 等打开。
- **velumd 接口**：`GET /v1/requests`（列表）、`GET /v1/requests/{id}`（详情）、`GET /v1/requests.har`；`vlu requests [-f]`。

## 限制

- **证书固定**的 App（部分银行、Apple 自家服务、部分 IM）解密后会连不上：只解密名单内域名，并有自动绕过。
- **网络扩展模式**：引擎在扩展里，同样可以做；根证书由 App 生成后经启动参数 / 接口交给扩展。
- **iOS**：需要安装描述文件并在「证书信任设置」里手动开启，放到 iOS 版再做。
- **性能**：只影响名单内域名的连接（多一次 TLS 握手 + 解析），其他连接零开销。

## 分期

1. **第一版**：根证书生成与信任、MitM 主机名、HTTP/1.1 解密、明文 HTTP 抓取、「请求」页、复制为 curl、HAR 导出。
2. **第二版**：HTTP/2、WebSocket（只记录握手与消息摘要）、证书固定自动绕过的界面提示。
3. **以后**：改写（Rewrite）、断点、iOS。
